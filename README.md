# Flask E-commerce Website

Website bán hàng được xây dựng bằng Python Flask, SQLite, HTML, CSS và JavaScript.

## Công nghệ sử dụng

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Jinja2

## Chức năng

- Đăng ký và đăng nhập tài khoản
- Quản lý thông tin người dùng
- Hiển thị danh sách sản phẩm
- Tìm kiếm và lọc sản phẩm
- Xem chi tiết sản phẩm
- Thêm sản phẩm vào giỏ hàng
- Đặt hàng
- Quản lý đơn hàng
- Quản lý sản phẩm
- Upload hình ảnh sản phẩm
- Phân quyền người dùng và quản trị viên

# cách Clone project
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
# Cài đặt thư viện
pip install -r requirements.txt
# Khởi tạo database
python init_db.py
# Chạy ứng dụng
python app.py
python app.py

# Cách chạy nhanh:
Cài Flask: pip install Flask
Lưu đoạn code trên vào file tên app.py.
Chạy lệnh: python app.py và mở trình duyệt tại [http://127.0.0.1:5000](http://127.0.0.1:5000).
